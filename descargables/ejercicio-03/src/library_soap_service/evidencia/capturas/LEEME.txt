CAPTURAS PENDIENTES DEL EJERCICIO 03 (módulo SOAP)
==================================================

Estas 23 capturas requieren PostgreSQL + el servicio Flask + la GUI Electron
corriendo en tu VM. NO se pueden generar en el entorno donde se armó el
módulo (sin Postgres). Este directorio trae:

  - LEEME.txt          (este archivo): los 23 nombres exactos + qué muestra cada uno
  - tomar_capturas.sh  : script que ejecuta los comandos de los pasos 1-6 con
                         banners; corre cada bloque en tu VM y captura la pantalla.

Guarda cada PNG con EXACTAMENTE el nombre indicado. Si más adelante armas el
reporte web, la galería de ejercicios/ejercicio-03.html los mostrará solo.

Orden = los 7 pasos del montaje en la VM.

PASO 1 — archivos en la VM
  paso1-archivos-en-vm.png        ls -R apps/services/library_soap_service/

PASO 2 — ambiente Python
  paso2-pip-install.png           pip install -r requirements.txt sin errores

PASO 3 — SQL del módulo
  paso3-sql-create-table.png      psql -f sql/soap_module.sql + _procedures + _privileges
                                  + _migracion, todos sin errores (CREATE TABLE/VIEW/ROLE)

PASO 4 — verificación del esquema propio
  paso4-verif-clasificadores.png  \d clasificadores
  paso4-verif-clasificaciones.png \d clasificaciones_cloud
  paso4-verif-clientes.png        \d clientes_servidos
  paso4-verif-duplicados.png      SELECT ... GROUP BY (id_clasificador,isbn,id_concepto)
                                  HAVING count(*)>1  -> 0 filas
  paso4-soap-user-denegado.png    conectado COMO soap_module_user:
                                  SELECT * FROM usuarios LIMIT 1;  -> permission denied

PASO 5 — servicio arriba
  paso5-servidor-corriendo.png    python app.py corriendo sin errores
  paso5-wsdl-respondiendo.png     curl http://localhost:5050/wsdl  -> XML del contrato

  paso6-n03-modelo-invalido.png        N03  modeloCloud=Xaas -> 400 DATOS_INVALIDOS
  paso6-n04-xml-invalido.png           N04  envelope sin cerrar -> 400 ENVELOPE_INVALIDO
